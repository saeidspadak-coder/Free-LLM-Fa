# راهنمای نصب و اجرای مدل‌های محلی (آفلاین و خصوصی)

اجرای مدل روی سیستم خودتان بهترین راه برای:
- استفاده نامحدود و رایگان
- حفظ کامل حریم خصوصی
- کار بدون اینترنت (بعد از دانلود مدل)

## گزینه ۱: Ollama (ساده‌ترین و پیشنهادی)

### نصب

**لینوکس / مک:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**ویندوز:** از سایت رسمی [ollama.com](https://ollama.com) دانلود کنید.

### اجرای مدل

```bash
# مدل سبک و سریع
ollama run llama3.2

# مدل قوی‌تر برای کدنویسی و فارسی
ollama run qwen2.5:14b

# مدل‌های دیگر محبوب
ollama run gemma2
ollama run mistral
ollama run phi3
```

### استفاده به عنوان API (سازگار با OpenAI)

Ollama به صورت پیش‌فرض روی پورت `11434` اجرا می‌شود:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama"  # مقدار دلخواه، مهم نیست
)

response = client.chat.completions.create(
    model="llama3.2",
    messages=[{"role": "user", "content": "سلام، امروز چه خبر؟"}]
)
print(response.choices[0].message.content)
```

## گزینه ۲: LM Studio (رابط گرافیکی زیبا)

1. از [lmstudio.ai](https://lmstudio.ai) دانلود کنید.
2. مدل مورد نظر را از داخل برنامه جستجو و دانلود کنید.
3. دکمه Start Server را بزنید.
4. از همان آدرس `http://localhost:1234/v1` در کدهای OpenAI استفاده کنید.

## گزینه ۳: llama.cpp (سبک‌ترین)

برای کاربران پیشرفته‌تر که می‌خواهند کنترل کامل داشته باشند.

```bash
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp
make
# سپس مدل GGUF را دانلود و اجرا کنید
```

## نکات فارسی‌نویسی

مدل‌هایی مثل **Qwen2.5**، **Gemma2** و نسخه‌های جدید **Llama** عملکرد خوبی روی فارسی دارند. بعد از نصب می‌توانید با پرامپت سیستم فارسی، خروجی بهتری بگیرید.
